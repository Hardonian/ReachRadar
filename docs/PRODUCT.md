# ReachRadar — Product Overview

## Mission
ReachRadar provides independent observability for recommendation algorithms. It helps creators, media studios, agencies, and publishers distinguish whether reach fluctuations are isolated to their content, cohort-wide, surface-specific, platform-level, or driven by external demand seasonality.

## Brand Positioning
- **Category:** Algorithm Distribution Intelligence
- **Tagline:** Know when distribution shifts — before your strategy does.
- **Short Promise:** See what changed. Know if it affects you.
- **Core Statement:** Algorithm intelligence. Not creator folklore.

## The Three Core Questions
Every feature answers:
1. **Did something unusual change?** (Statistical volatility detection across surfaces)
2. **Is it affecting channels like mine?** (Hierarchical matched cohort consensus)
3. **Should I change anything?** (Deterministic prescriptive strategic advice)

## Customer Segments
- **Solo Creator (1–5 channels):** Quick sanity checking on view drops.
- **Studio / Production Team (5–25 channels):** Cross-channel benchmark baselines and multi-seat workflows.
- **Agency / MCN (25–100+ channels):** Client rosters, bulk alerts, and white-label client reports.
- **Publisher / Media Network (100+ channels):** Enterprise API, programmatic exports, custom cohorts.

## Invariants
1. Private creator data never becomes public raw data.
2. The LLM never decides whether an algorithm shift occurred.
3. Public shift publishing requires $\ge 25$ channels and $\ge 10$ distinct owners.
4. No scraping or undocumented YouTube endpoints.
5. No claims of possessing proprietary YouTube ranking neural network weights.
